# 09. かつめしの地域資料・権利上の注意

## 事実確認（2026-11-22時点）
- 加古川市のかつめしは、洋皿のご飯に平たいビーフカツを載せ、デミグラス系のたれを掛け、茹でキャベツを添え、箸で食べる郷土料理として紹介されている。
- 戦後間もない頃、加古川駅前の食堂で「箸で気軽に食べられる洋食」として考案されたと伝えられている。
- 現在はビーフに加え、ポーク・チキン・エビなどのバリエーションや、店舗ごとに異なるたれが存在する。
- かつめしは文化庁の「100年フード」に認定されている。
- 5月29日は「かつめしの日」とされ、地域のPRに使われている。

## ライセンスと公開時のチェック
- 実在店舗の店名/看板/ロゴ/メニュー画像、観光協会の公式マスコット「かっつん」「デミーちゃん」のイラストや名称をゲーム素材に使う際は別途許諾を確認。
- 公式サイトの写真・地図は参考閲覧用途。ゲーム中での転載やアセット化には権利確認が必要。
- 生成AIのモデル、LoRA、参照素材、フォント、音楽、効果音の利用条件をmanifestで追跡する。
- 郷土料理についての一般的な事実と、ゲーム固有の数値・調理タイミング・台詞・架空店設定を区別する。
