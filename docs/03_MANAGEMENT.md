## 1食の経済モデル（ビーフの初期値）
| 材料 | 初期原価 |
| --- | ---: |
| 牛肉 | 250円 |
| 米 | 60円 |
| 衣（パン粉・卵等） | 40円 |
| たれ | 50円 |
| キャベツ | 30円 |
| **合計** | **430円** |

初期販売価格980円、単純粗利益550円/食。10食販売なら売上9,800円、消費原価4,300円、固定費2,200円、会計上の日次営業利益は3,300円（例、スタッフ人件費0円の場合）。この数値は現実の価格の主張ではなくゲーム上の仮値。

## 在庫・会計の整合性
- 仕入時: 現金減・在庫増（原価を支払う）。
- 調理開始時: 食材確保、調理済なら在庫減・売上原価計上。
- 提供時: 売上計上・現金増。退出/破棄は売上0、消費済材料をロスに集計。
- 閉店時: 固定費・人件費を現金から支払う。
- 日次営業利益 = 売上 - 消費材料原価 - 固定費 - 人件費。
- **現金増減 = 売上 - 仕入支払 - 固定費 - 人件費**。営業利益と現金増減を混同しない。
- Day 1の初期10食分は「開業支給の初期在庫」として初期資産に含め、Day 1では仕入支払0円。未使用在庫はDay 2へ繰り越す。
- 現金不足で仕入不可なら可能なメニューのみ営業。固定費で現金がマイナスになった場合は借金表示（上限-10,000円、立て直し策を案内）とする。

## 注文と客の意思決定
顧客ごとに味の好み3値と待ち時間倍率を持ち、入店時に注文候補と台詞を生成する。
| タイプ | 性格/ヒント | 配合好み(甘/コク/酸) | 待ち時間倍率 |
| --- | --- | --- | --- |
| 近所の常連 | バランス重視、会話多め | 50/60/40 | 1.2 |
| 学生 | 甘め・ボリューム好き | 80/50/20 | 0.9 |
| 会社員 | 濃厚でスピーディ | 30/90/30 | 0.8 |
| 観光客 | 少し酸味のある新鮮さ | 40/50/80 | 1.0 |

- 実待ち上限 = 基本90秒×倍率。
- 料理評価が高いほど会計後の満足演出・口コミ値・再来店確率が上がる。
- 顧客の好みヒントは注文カードに1つ以上表示する。
- 顧客の未観測の好みは顧客ノートへ徐々に記録する。

## 評判（暫定式）
各提供の評判変動 = SSS:+4 / S:+3 / A:+1 / B:0 / C:-2 / F:-4。待ち時間切れ:-2。評判は0〜100へclamp。初期は配合の影響と工程熟練で少しずつ上がるバランスとする。高評価で来客上限や新客解放、低評価では伸びが緩やかになる。

## 価格調整と需要
- MVPは基本980円で固定、価格UIは将来拡張用表示のみ。
- v1: 50円刻みの価格変更、価格が基準から+20%で来客確率に小さい減衰、-20%で小さい増加。
- 価格を上げても過剰利益にならないよう客数とのトレードオフを検証する。

## アップグレード（MVP）
| 設備 | コスト | 効果 |
| --- | ---: | --- |
| 新しいフライヤー | 8,000円 | 揚げ判定の許容時間を+1秒 |
| 店内の快適な椅子 | 5,000円 | 待ち時間上限+10% |

解放購入は営業時間外に限定し、1回購入のみ。値段と効果はデータで変更可能にする。

## イベント
| イベント | 起動条件 | 効果 | 状態 |
| --- | --- | --- | --- |
| 昼の混雑 | 通常日ランダム | 来客間隔短縮 | v1 |
| 雨の日 | 日次抽選 | 客数減・常連割合増 | v1 |
| 口コミで話題 | 高評価連続 | 新規客増 | v1 |
| 食材値上がり | 日次抽選 | 仕入価格上昇 | v1 |
| 商店街の祭り | ストーリー進行 | 限定注文 | v1 |
| かつめしの日（5/29） | ゲーム内の5/29 | 専用イベント/演出 | v1 |

イベントは同時に最大2個。発動理由・持続日数・プラス/マイナス・終了をUIに表示。MVPはイベント基盤のみ用意し、固定チュートリアルと通常営業を優先。

## 破綻救済
在庫がなくなった日の翌朝は最低限の仕入れ提案を出す。赤字が続いたら無料の短い立て直し依頼を提供。突然のゲームオーバーではなく再挑戦する動機を作る。

## バランス検証指標
- 初回の普通プレイでDay 1に黒字が出やすい（70%以上、要テスト）。
- 上手な操作で得点が伸びるが、Fが1回出ても即座に資金難には陥らない。
- たれ研究と設備購入の両方が3日以内に体験できる。
