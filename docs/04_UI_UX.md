# 04. 画面設計・UI/UX

## UI方針
- 画面全体はアニメ調で、木目・暖色・デミグラスの深い茶色をベースに「おいしそう」と「操作しやすい」を両立。
- 一番重要な料理とキャラクターの顔に視線を集め、数値はその理解を補助する。
- PCブラウザの基準解像度1920×1080（16:9）。1280×720で文字切れ・被りがないようにする。
- 可読性重視、長い説明はポップアップで表示。誤入力した操作を取り消す方法を用意。
- キャラクター反応が画面の主役となる瞬間はHUDを控えめにする。

## 画面一覧・遷移
1. タイトル: ニューゲーム / コンティニュー / 設定 / クレジット
2. 朝の準備: 在庫・仕入れ / たれ研究 / 本日の売れ筋予測 / 開店
3. 営業（店舗）: 店内・キュー・営業残時間・現金・評判・イベント・注文開始
4. 調理（キッチン）: 工程進行・道具・ゲージ・作っている料理・戻る
5. 試食リアクション: 完成料理拡大＋客の立ち絵＋感想＋評価
6. 閉店結果: 売上内訳・経費・満足度・評判差分・今日の出来事
7. 設備/アップグレード: 所持金・アップグレードの比較・購入
8. 設定/ポーズ: BGM/SE/文字速度/解像度/操作説明/再開/セーブして終了

ゲーム内メニューは朝・営業・閉店で表示する項目を変える。SHOPや図鑑のような機能はv1以降の実装前には操作不能ボタンとして残さない。

## 主要レイアウト（16:9）
### 店舗画面
- 上部高さ8%: 営業日・残り時間、資金、評判、ポーズ。
- 左側幅18%: 店内状況、客の簡易ポートレートと待ち人数。
- 中央幅56%: 2D店舗シーン、入口、テーブル、厨房入口（クリック対象）。
- 右側幅26%: 注文カード最大3枚、待ちゲージ、注文の選択。
- 下部高さ12%: 接客メッセージ、次の推奨アクション。
- 右側パネルの縦スクロールはカードが増えても画面を押し潰さない。

### 調理画面
- 上部: 工程ステップ（P1〜P6）と残り時間。
- 中央: 調理対象を大きく描画。操作説明を対象物のそばに表示。
- 左下: 客の注文・好みの短いヒント。
- 右下: 進行/やり直し/一時停止。重要ボタンは毎画面で位置固定。
- 操作中は非対象工程UIを暗くし、クリック範囲を明示。

### 試食画面（重要演出）
- 左寄り: 顧客の上半身立ち絵を大きく表示。ランク別の表情・ポーズ差分。
- 手前中央〜右: 完成したかつめしの皿を大きく表示。
- 下部左寄り: セリフウィンドウ、短い感想。読みやすい背景あり。
- 評価: SSS / S / A / B / C / F を大きく一度だけ表示。
- 高ランクほど光・湯気・粒子・画面揺れ（軽度）を強め、C/Fは落胆の差分で演出。
- スキップ入力時は最終状態へ即遷移、リワード確定は1回に限定。

## ビジュアルの優先順位
1. 料理の美味しさ（主役は完成したひと皿）
2. キャラクターの表情・ポーズと評価
3. 分かりやすい調理操作
4. 店舗の温かい雰囲気
5. 経営数値とイベント情報

## 入力仕様
| 入力 | 動作 |
| --- | --- |
| 左クリック | 決定、工程選択、注文選択 |
| 左ドラッグ | 衣付け・盛り付けなど |
| Esc | ポーズ / 開いているモーダル閉じる |
| Enter / Space | セリフ送り、確認（設定可能） |
| Tab | フォーカスを次の操作要素へ |
| R | 現在工程の再試行（利用可能時のみ） |

キーボードでもUIは操作できる。調理のドラッグ工程はMVPでは代替としてクリック順操作も提供し、ポインターの精密操作が苦手でも完走できるようにする。

## 必須フィードバック
- 押せるボタンにはホバー/フォーカス/押下の状態がある。
- 購入ボタンは支払額・購入後残額を表示。
- 在庫不足は注文開始前に分かる。
- レシピ変更は即プレビューに反映し、確定しなければ元に戻せる。
- ゲーム内時間の進行/停止が分かる。
- 操作ミス・失敗は小さな注意書きで具体的に表示し、エラーを隠さない。

## アクセシビリティ
- 標準本文: 基準1920×1080で概ね20〜24px、最小UIラベル18pxを目安。1280×720でも視認できるよう実機確認。
- スコアは色だけに依存せず文字・アイコン・音でも区別。
- 光や画面揺れを削減する設定、SE/BGM別音量、セリフ自動送りOFF。
- 日本語優先。すべてのセリフ・UI文字列はハードコードせず文字列IDで管理。
- 画面端でモーダルがはみ出さず、スクロール領域をフォーカスできる。

## UI検証に必要なモックアップ
- タイトル / 朝準備 / 店舗営業 / 調理P1・P3・P6 / 試食SSS・B・F / 結果 / 設備の計10画面以上。
- 1920×1080と1280×720の両方で検証。
- モックアップは配置判断のための資料であり、完成ゲームのアセットと混同しない。
