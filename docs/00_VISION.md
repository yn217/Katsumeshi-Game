# 00. 企画概要・ビジョン

- 仮タイトル: **かつめし繁盛記 ～加古川の一皿～**
- ジャンル: 調理アクション + 店舗経営 + キャラクター交流
- 舞台: 加古川に着想を得た架空の商店街（実在店舗の再現・公式認定を主張しない）
- プラットフォーム: PCブラウザ先行（キーボード・マウス）、タッチ操作は後続
- 画面: 横長16:9、2Dアニメ・イラスト主体
- 状態: 仕様 v0.1、すべての経済数値・時間は暫定

## 一文で表すゲーム
「カツを揚げ、秘伝のたれを育て、ひと皿の感動で街の人気店になる。」

## プレイヤー体験
1. 「うまそう」を作る: ご飯・ビフカツ・濃厚なたれ・茹でキャベツが気持ちよく仕上がる。
2. 「食べてもらう」: 味が好みに合うとキャラクターが大きく喜び、低評価でも愛嬌ある反応が返る。
3. 「次を試す」: 口コミ・客層・季節を読み、調理技術とたれ配合を改善する。
4. 「店を育てる」: 稼いだ資金で設備・内装・メニューを増やし、常連と地域イベントを解放する。

## 他の料理経営ゲームと差別化する点
- デミグラス系の**たれの味パラメータ**が主役。最適解1つではなく客の好み・イベントによって成功配合が変わる。
- **一皿完成時の料理の見映え**を強く演出し、食後の立ち絵リアクションを報酬にする。
- 現実の郷土料理の特徴をベースにし、料理を作るほど加古川文化に触れられる。
- 「ビフカツを平たくする」「洋皿と箸」「茹でキャベツ」という特徴をプレイに落とし込む。

## 想定プレイヤー
- 料理ゲームや経営シミュレーションを短時間楽しみたい人。
- かわいいキャラクターとの会話・リアクションを楽しむ人。
- ご当地料理や地域文化に興味のある人。

## プレイ時間・ゲームテンポ
- チュートリアル: 約5〜8分（目標）
- 通常1営業日: 約8〜12分（目標、実時間）
- 1セッション: 1〜2営業日
- 長期目標: 第1週に店の基礎を整え、第2週以降にメニュー・施設・イベントを増やす

## スコープ
### MVPに入れる
1店舗、調理6工程、ビーフかつめし1種、たれ調整、客4種、注文・待ち時間・会計、1日営業結果、簡易店アップグレード2種、ローカルセーブ、試食リアクション6ランク。

### v1以降
ポーク/チキン/エビ、複数のたれレシピ、常連シナリオ、店舗レイアウト、スタッフ、季節イベント、5月29日のかつめしの日、町マップ、実績、写真風料理アルバム。

### 企画段階の非目標
オープンワールド、オンライン対戦、課金・広告、実店舗の位置・値段再現、レシピの現実的な栄養・衛生教育、3D自由移動。MVPでこれらを実装しない。

## ゲームデザイン上の原則
- 数字の改善だけでなく、見た目・音・反応で成長を伝える。
- 調理ミニゲームの失敗は食材ロスだけでなく品質にも反映。ただし途中で必ず詰まる仕様にはしない。
- 調理しない待ち時間は最小化。スキップ可能な演出を用意する。
- キャラクターはオリジナル創作を基本とし、権利が不明な既存マスコット・人物は使わない。

## 主要KPI（社内評価用、暫定）
- 初回チュートリアル完走率: プレイテストで80%以上を目標
- 調理工程を理解できた率: 5人中4人以上
- 1皿の完成後「次も作りたい」と感じる率: 5人中4人以上
- 不具合: 進行不能0、セーブ破損0
- フレームレート: 一般的なPCブラウザで目標60fps
