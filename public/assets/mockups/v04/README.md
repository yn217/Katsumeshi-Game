# かつめし繁盛記 UIモックアップ v0.4

## 内容
- 08_serving_oblique.webp: 斜め見下ろし型の配膳ゲーム画面（昼営業ラッシュ）

## 方向性
- 調理は1日1回（開店準備）にして、その日の料理品質を決める。
- 営業中は、厨房で自動的にできあがったかつめしを、店員がトレーに載せて席まで運ぶ。
- 店内をクリックすると店員が歩いて移動する。細かい道をなぞる操作はしない。
- ゲーム性は「どの席から回るか」で作る：運べる皿数（初期2皿）、席の位置、お客さんの残り待ち時間。
- 満足度 = 料理品質 + 好み一致 + 配膳評価 + 接客補正。

## 画面構成
- 上部：メニュー（店舗営業・配膳・経営・スタッフ）、日数、時間帯、資金、評判、残り時間。
- 左上：今の目標（例：6卓に配膳しよう、配膳済み 2/6卓）。
- 中央：斜め見下ろしの店内。厨房の受け渡し口、テーブル番号、料理の吹き出し、待ち時間ゲージ、急ぎ表示。
- 右側：配膳待ちリスト、トレー（2/2）、配膳ルート表示、営業を進める。
- 左下：看板娘の立ち絵とヒントの吹き出し。

## 注意
ImageGen で作ったレビュー用の画面イメージです。文字や数値はラフで、仕様の根拠にはしません。
実際に動く試作は `prototypes/serving/index.html`（開発サーバーで `/prototypes/serving/index.html` を開く）にあります。

## ゲーム本編への組み込み（2026-11-24）
- その日の最初の注文だけ、これまでどおり調理ミニゲームで作る（今日の仕込み）。
- 仕込みの結果が、その日の料理品質になる。2組目以降は店内画面（`src/serving.mjs`）で、厨房が作った料理を席まで運ぶ。
- 配膳時の評価は、仕込みの品質とお客さんの好みで決まる（`SERVE_TABLE`）。待たせた時間は評判に影響する（2日目以降）。
- 背景と店内キャラ：`public/assets/game/serving/v01/`（床の背景、SD店員、座っているお客さん、料理人）。
- テーブル・椅子・受け渡し口の位置は `src/serving-layout.mjs` が唯一の定義。背景はこの配置から作ったレイアウト図を ControlNet に通して生成しているので、配置を変えたら背景も作り直す。
- 見た目の確認は `prototypes/serving/index.html`（本物の `src/serving.mjs` を仮の注文データで動かす確認用ページ）。`?ff=30` で30秒早送り。
