銀髪（ラベンダー系）、両側のお団子、ピンク色の瞳とヘアピンを統一。服装は指定された参考画像の青デニムをコピーせず、ゲーム用に生成した制服を使用。

注意：01〜05は一枚に生成された5画面コンセプトの各パネルを切り出し、16:9の確認用キャンバスに再配置したレビュー用モックアップです。文字やレイアウトはラフ段階です。実装画面への直接使用は非推奨で、最終アセットには画面単位の再生成/部品分割とUI組立が必要です。

### 既知の要修正点
- 生成イメージに仕様の定義と異なる人数・値・表記が含まれる可能性があります。
- 業務ロジックは仕様書v0.2を正とし、画面内の数字やテキストは仕様の根拠にしないこと。
- タイトル/立ち絵と個別画面で服装の違いがあるため、ゲーム内正式衣装（例：白ブラウス+えんじ色のエプロン）を統一すること。
- SSS試食シーンは演出構図の参考であり、店主と評価を出す顧客の役割は実装時に明確に分けること。
