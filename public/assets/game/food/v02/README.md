## 工程/食材
`ingredients/` に薄く伸ばした生肉、粉、衣、揚がったカツ、茹でキャベツ、炊いたご飯、デミグラスソース、盛付け例を個別保存。
`process/frying_thin_cutlet_v02.webp` は揚げ工程の単独画像（以前生成したもの）。

## 品質と用途
- 全素材 `concept_review`。ランク6枚＋食材8点は**複合生成画像からの切り出し・拡大**であり、独立高解像度生成品ではない。画質・背景の境界・切り出し内の混入を確認すること。
- ランク表示の文字やUI部品は別レイヤーで描画する。料理画像をSSS等の背景UIと一体化しない。
- Webゲームでは `src/main.mjs` の`assetForStage`/`assetForRank`で直接参照する。
- 本ディレクトリには軽量WebPを収録。編集用PNGは会話内のZIPで提供。
- 正式採用へ進む前に、薄さ、茹でキャベツ、統一視点、透明背景、切り抜き端、F評価の過度な不衛生表現などをレビューする。
